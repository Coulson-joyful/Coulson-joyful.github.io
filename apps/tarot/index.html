今天，想怎么开始？

不需要每次都做一场完整阅读。根据当下的需要，选一个入口就好。

每日一牌

抽一张今天的牌，读一个具体提醒。首次保存后，当天结果保持不变；换语言或换牌面，不会重新抽取。

称呼与生日均可选

03 / GETTING STARTED

一次阅读，
从一个具体问题开始。

第一次可以先用每日一牌。想讨论一件事时，再选择单牌或适合的牌阵。无需注册账号，也不必先填写个人档案。

提问示例“最近的合作沟通有点卡住，我可以先调整什么？”
写清正在发生什么、想做什么决定，比只问一个确定结果更便于解读。

选一种方式

看当天提醒选每日一牌；比较选择用岔路之镜；想换个观察角度，可以掷骰或翻一页回应。

写下问题，再抽取

提问可选。没有具体问题时，应用按牌面与牌位解释，不自行补写你的经历。

先看解释，再看依据

正文直接讲牌意和可做的动作。牌名、正逆位、画面与资料放在详情，方便需要时核对。

v9 解读示例 · 女祭司逆位

先别把强烈的感受当成已经证实的判断。分清直觉、期待和猜测，别为了显得懂而仓促表态。

今天可以做：先写下一个已知事实和一个待确认的问题，核实后再回复。

为说明展示方式而节选；这不是对你的实际处境作出的判断。

回到历史，补写现实反馈

记录后来做了什么、发生了什么。保留原解读，方便区分当时的想法和后来的事实。

需要迁移时，手动备份

从「历史 → 历史备份」导出，在另一设备选择文件后合并恢复。当前不会自动跨设备同步，导出文件未加密。

06 / PRIVACY, WITH CLEAR BOUNDARIES

写给自己的话，
先留在自己的设备上。

当前应用的抽牌、牌阵、占星骰、一页回应和历史在本地运行。没有应用账号、广告、行为统计或接收提问的自建服务器。

“本地保存”与“应用层加密”是不同的保护。下面分别列出已实现的行为和下一阶段的设计，避免把计划写成已有承诺。

当前已实现

解读不发送到第三方 AI 接口

内置规则直接在设备运行。支持的设备可使用 Apple 本机模型，当前接口仅接收本次问题、牌阵与抽到的牌，没有整库历史读取工具。

当前已实现

历史可查看、删除和手动备份

记录、复盘与回应页快照保存在本机。购买权益与历史分开；删除历史不会撤销已购牌面。导入 PDF 的整本文件不随历史备份迁移。

当前已实现

网络使用有明确场景

Apple 购买和恢复购买需要联网。主动打开来源链接、访问支持页面或发送邮件，会使用相应系统应用和服务；网站托管方可能处理 IP 等访问日志。

计划增加 · 尚未实现

身份验证 + 独立历史加密

设计方向是由 Face ID、Touch ID 或设备密码保护密钥访问，再解密历史。当前版本没有这道历史访问锁，文件也尚未增加独立的应用层加密。

当前历史 JSON 与手动导出的备份未做应用层加密。系统备份可能包含应用数据；把备份存进云盘后，也适用所选服务的规则。删除 App 内记录不会删除已导出的文件。

08 / GOOD TO KNOW

使用前，你可能想知道。

需要注册、填写生日，才能抽牌吗？

不需要应用账号。称呼和生日都可选；不填写档案，也可以使用每日一牌与其他阅读功能。

断网后还能使用吗？

核心抽取、内置资料和历史可在本地使用。本机模型需要设备支持且模型已准备好；购买与恢复购买需联网，来源网站和邮件也依赖相应服务。

一页回应和商业《答案之书》是什么关系？

App 的功能名称是「一页回应」，采用中英文各 400 条项目原创回应，使用 AI 辅助编写，不是商业《答案之书》的复制或翻译。也可以导入自己有权使用的 PDF。

换皮肤或切换语言，会重新抽牌吗？

不会。视觉与语言设置不改变已经抽到的牌。旧历史保存的是当时的问答快照，因此可能保留原语言；每日一牌仍沿用当天保存的结果。

历史能自动同步到另一台设备吗？

目前不能。使用「历史备份」手动导出并合并恢复；重复导入不重复新增，同一记录及同一天每日结果以本机为准。备份有 100 MB 限制，合并后超过上限也不会导入。当前备份未加密。

怎样删除自己的资料和文件？

历史中可删除记录；「资料 → 隐私政策」中的彻底删除历史还会移除无法读取的恢复副本。称呼与生日在档案页删除；导入 PDF 在一页回应中删除应用内副本。历史中的原页快照、已导出文件和系统备份需分别管理。

AI 会替我决定、预测别人的想法吗？

解读提供反思角度，不能确认他人心意或未来事件。应用区分传统资料和应用解释，并保留来源；内容不能替代医疗、法律、财务或心理专业意见。

现在就有 Face ID 加密保护了吗？

还没有。当前没有独立的历史访问锁，也没有历史应用层加密。相关安全能力尚在计划中，完成实现与验证后才能作为正式功能提供。
