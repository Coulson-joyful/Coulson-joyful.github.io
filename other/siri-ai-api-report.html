03

哪些是中国大陆限制，哪些不是

官方明确列出的限制

  • Apple Intelligence：当前公开支持页仍说明，中国大陆购买的支持设备受限；非大陆购买设备在身处大陆且 Apple 账户地区也为大陆时同样受限。官方条件
  • Siri AI：当前支持页说明，Apple 账户地区为中国大陆时不可用。官方条件
  • Siri AI 语言：当前 27.3 公告与支持页列出英语、法语、日语、韩语、葡萄牙语和西班牙语；未将简体中文列为新 Siri AI 的支持语言。Apple Intelligence 整体支持简体中文并不等于 Siri AI 也支持。最新预览公告
  • ChatGPT 扩展：还受扩展服务本身的地区可用性限制；本次未测试，不能承诺大陆设备可用。Apple 扩展说明

不能直接归为地区限制的结果

  • deviceNotEligible 没有给出独立的地区原因字段；不能由它确定唯一原因。
  • PCC 缺少托管权限、测试分发条件不满足，属于开发者／工程条件。
  • 缺少 SiriKit entitlement 是签名问题；不是大陆封锁。
  • 27.3 新 API 在 27.2 SDK 中不能编译，是工具链条件。
  • 语音资源未就绪、单次或重复超时，需要继续排查，不能据此宣布整类 API 在大陆不可用。
公开限制与测试版局部表现存在差异：本次用户在国行测试设备上已操作成功 Siri 快捷操作和写作工具。报告保留该事实，同时保留官方限制；不会据此推断所有国行设备、所有账号或所有模型接口都已开放。普通 Siri 快捷操作成功也不等于新 Siri AI 的所有功能成功。
04

iOS 27.3 新预览：已核对，尚未具备实测环境

Apple 于 2026 年 11 月 3 日发布 Siri AI 开发者预览。新的接入方向是让 Siri 调用 App 明确提供的工具、查找实体及组合动作；它与 App 内直接发 prompt 给 Foundation Models 是不同路径。官方公告

自定义 Siri 工具

@AppIntent(.tool) 将动作标记为 Siri 可调用的工具。当前主机 SDK 只有 27.2，本次编译负例确认缺少新宏签名。

已成功的 App Shortcut 是标准快捷操作入口，不能代替这项新预览的自然语言规划与工具调用验收。

Siri 自动化评测

SiriEvaluations 能脚本化请求并检查 Siri 调用了什么动作、找到什么实体、回复了什么。本机编译确认没有该模块。

这属于开发评测接口，不能当作产品中绕开地区或模型资格的任意对话 API。

开发者预览还限定支持设备／地区与分发方式；官方文档允许开发签名和内部 TestFlight 测试，并未对外部 TestFlight 或商店用户开放此预览。此次没有安装匹配的 27.3 SDK，也未修改系统设置来尝试绕过限制。预览条件

06

开发时现在可以采用什么

可以推进的接入

  • Siri 执行动作：标准 App Intents + App Shortcuts 可作为目前已得到人工验证的入口。为每个真实业务动作单独验证参数与权限。
  • 用户发起文本润色：系统文本控件的写作工具路径值得使用；本次已人工操作成功。
  • 基础语音／翻译：公开 API 的支持检查能返回信息，但需要补齐资源或继续排查后，再以真实结果决定是否采用。

暂不能承诺的能力

  • App 内任意 prompt 生成：本机 Foundation Models 端侧接口未开放资格；不能以写作工具成功替代。
  • PCC 云端推理：先取得 Apple 托管权限与符合条件的测试分发，再在目标设备验证。
  • Siri 任意内部模型选择：本次核对的公开接入路径不提供一个通用的“选择 Siri 内部供应商／型号并发请求”的生产 API。
  • 27.3 新工具规划：需要匹配 SDK 和支持 Siri AI 的环境，不能从旧快捷动作成功外推。

写作工具是用户可见的系统交互，不是可以在后台静默调用的通用生成替代品；Shortcuts 的模型选项也是用户工作流入口，不能直接等同于 App 的模型 API。

07

尚需补测的具体项目

  1. 匹配的 27.3 开发工具链

    升级后重新编译 ToolIntent 与 SiriEvaluations，先验证一个固定响应动作，再测自然语言变体、参数和实体查找。

  2. 快捷指令中的四类模型入口

    在 iPhone 的“使用模型”动作中，分别记录 On-Device、Cloud、Cloud Pro、Extension Model 是否出现、能否运行及错误提示。固定提示可用“用一句话描述雨后的花园”。本轮均未执行，不填造结果。

  3. PCC 的权限与分发对照

    取得权限后按官方支持的 TestFlight 或 ad hoc 路径验证，再比较设备购买地、账号地区、语言和实际地区条件。无需为了本报告更改现有账号。

  4. 语音资源与合成问题

    检查具体中文模块资源与声音下载状态，补测普通播放和缓冲区生成，再执行固定音频转写；两次超时仍不足以定位地区原因。

  5. 写作工具输出与离线表现

    补采实际变更文本和操作种类；如需区分端侧／云端，可设计联网与离线对照。当前没有后端或离线能力结论。

09

本次核对的 Apple 官方来源

核对日期：2026-11-10。系统测试版的局部表现、公开支持页、开发者资格与 SDK 能力分别记录；不假设它们已完全同步。

  1. Apple Intelligence 地区说明

    公开说明仍列出中国大陆购买设备限制；设备购买地、Apple 账户地区和所在地区是不同条件。

  2. Siri AI 支持语言与地区

    当前页面列出六种支持语言，并说明 Apple 账户地区为中国大陆时 Siri AI 不可用。

  3. 27.3 开发者预览公告（2026-11-03）

    新预览向开发者开放的是 App 内容与动作接入；不等于开放任意 Siri 内部后端模型选择。

  4. Siri AI Developer Preview

    仅在支持设备与地区提供；开发签名与内部 TestFlight 可测试，外部 TestFlight／商店用户不属于该预览的开放对象。

  5. Siri ToolIntent

    @AppIntent(.tool) 将自定义动作标记为 Siri 可调用工具。

  6. Siri Evaluations

    通过脚本对话测试 Siri 的意图调用、实体查找和回复，要求匹配的新工具链。

  7. PCC 资格与分发条件

    需满足小型企业计划、下载量条件及专用权限；测试分发路径包括 TestFlight 与 ad hoc，以官方说明为准。

  8. PCC 托管权限

    com.apple.developer.private-cloud-compute 需申请，不能仅手工添加布尔值取得权限。

  9. Foundation Models 生成与可用性

    在模型可用时才发起生成，并准备不可用时的替代体验。

  10. Shortcuts 模型选项

    iPhone 文档列有 On-Device、Cloud、Cloud Pro 和 Extension Model；这是用户工作流中的模型选项。

  11. ImageCreator 终止公告

    Apple 已宣布旧 ImageCreator 非 UI 接口不再适用于 iOS 27；推荐系统图乐园界面。

  12. 写作工具系统界面

    通过系统文本控件／协调器接入写作体验，不能视为任意后台 prompt 接口。

  13. SpeechTranscriber

    检查硬件、语言与已安装资源；这些条件仍需与实际转写结果区分。

  14. SiriKit 与现代 App Intents

    旧 SiriKit 保留兼容支持；现代 Siri AI 接入采用 App Intents。
